# 2.10.0

## Configurable token budgets

- Expose a maximum context-window planning ceiling (default 220,000 tokens) and a maximum per-response output budget (default 32,000 tokens) in installation configuration.
- Apply the output budget to technical planning, candidate review, build selection, and specialist work responses. Keep the output budget below the configured context ceiling.
- These settings do not expand the selected model's actual context window or provider output allowance. No new capabilities or permissions are requested.
- Update to WorkManagement.Contracts 3.23.0, the minimum required by Agent SDK 3.47.0. No breaking configuration changes.
