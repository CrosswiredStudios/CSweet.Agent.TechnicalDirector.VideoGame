# 5.0.10

Source-coverage requests use compact page-local source and story indexes instead of repeatedly generating long canonical keys. The agent resolves indexes back to the exact frozen identities and retains every accepted-source coverage check. Existing validated outline and coverage checkpoints remain readable and unchanged.

Planning now reports completed outline and coverage page counts. Scope-manifest guidance groups related requirements into meaningful increments instead of promoting every implementation detail into an Epic/Story pair; frozen manifests are preserved.

Regression tests cover invalid indexes, complete source preservation, compact request size, existing checkpoint recovery and page progress. Full agent tests, published-output self-test and package metadata verification validate this release.
