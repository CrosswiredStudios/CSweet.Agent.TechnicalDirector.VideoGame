# 5.0.11

Incremental planning now supplies the canonical board as an identity, hierarchy, dependency and status ledger instead of copying every published item's full requirements, criteria and repeated global constraints into the prompt. Regressions cover a 126-item backlog, scope/criterion preservation, completed status, dependencies and legacy full-context behavior. Full tests, published-output self-test and package metadata verification validate the release.
