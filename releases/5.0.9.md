# 5.0.9

Planning response schemas now require an object at the root. The .NET schema exporter otherwise permits a null root for reference types, which OpenAI-compatible structured-output providers reject before planning begins. Nested field schemas, exact accepted-source coverage, role validation and retained planning checkpoints remain enforced.

Six regressions cover scope manifests, outline pages, coverage, metadata corrections, full plans and incremental task indexes. Full agent tests, published-output self-test and package verification validate the release.
