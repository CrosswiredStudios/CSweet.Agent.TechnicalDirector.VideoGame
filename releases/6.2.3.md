# 6.2.3

Moves to `CSweet.Agent.SDK` 5.23.1 (was 5.23.0). No agent code changed. No manifest, capability, grant or configuration
change.

Fixes an increment acceptance that QFN Games could not pass on 2026-11-12. As the increment's technical reviewer, this
agent approved every acceptance criterion and its whole-candidate consistency check found nothing blocking, yet it
submitted `changes_requested` with 21 findings. They were notes from the bounded source inspections that run before a
large review (observations, optional robustness ideas, and a "missing" script that was in another part), which the SDK
appended to the verdict. The board showed "No additional blocking consistency findings…" as the block reason.

With SDK 5.23.1, inspections separate notes from defects and see the full file list. Each defect is ruled on against
the whole candidate: a genuine or uncertain one blocks, and a dismissal needs a reason that is kept with the outcome
(`sourceInspectionRulings`). A rejection's summary now starts with "Changes requested (N blocking findings): …".

To re-run a review rejected this way, retry the blocked ticket after updating.
